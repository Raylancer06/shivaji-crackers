# Shivaji Crackers - Sivakasi Direct Wholesale Fireworks Store

Official Next.js e-commerce platform and wholesale price list portal for **Shivaji Crackers**, Sivakasi.

## Features
- **Cinematic Hero Carousel**: Multi-slide festival showcase with auto-play and instant SKU cart add.
- **Bestseller Featured Carousel**: Curated Diwali picks right on the homepage.
- **Dedicated Estimate Portal (`/estimate`)**: Complete 157-product price list across 16 categories with vertical Side Tabs.
- **Wholesale Price Sheet Table & Visual Cards**: Dual view modes with instant search and category filtering.
- **Dual Checkout System**:
  - Direct 1-Click WhatsApp Order dispatch (preset with test helpline `+91 8318270300`).
  - Form Checkout generating printable estimate invoice.
- **The Way We Work (5-Step Process)**: Transparent workflow from factory curation to regional lorry transport.
- **Multi-Page Experience**:
  - `/` - Homepage with Hero, Bestseller Carousel, Budget Estimator, and Specifications.
  - `/estimate` - Standalone full catalog with 16 category side-tabs and instant estimate calculator.
  - `/payment` - Verified bank transfer (Bank of Baroda, Sivakasi) & UPI details.
  - `/about` - Brand heritage since 2017 and 5 festive pillars.
  - `/contact` - Sivakasi Godown and Hyderabad transport terminals.
- **100% CSIR-NEERI Green Certified & PESO Compliant**: Adhering strictly to Hon'ble Supreme Court directives.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS with Mona Sans typography
- **Animations**: Framer Motion & Canvas Confetti
- **Icons**: Lucide React

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev -p 3001
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
